运行时

随包只有 node.exe、npm 和 dsh 本体；依赖在第一次启动时从 npm 源下载安装（约 835MB，1–2 分钟），之后秒开。安装过程关闭了第三方安装脚本（--ignore-scripts），并按 package-lock 校验完整性。

怎么用

  1. 点「安装并启动」。首次会先装依赖，再起 dsh，最后单独开一个窗口。
  2. 窗口里选一个工作目录就能开工；窗口关掉只是关界面，dsh 还在跑。
  3. 模型与凭据在 dsh 自己的设置里填；这里只管启停，不代管任何钥匙。

注意：DeepSeek Harness 会用你填的账号把对话发到 DeepSeek 的服务器，这是它本身的工作方式，不是本软件在收集。关掉宿主会一起收掉 dsh 和它的窗口。

洛希通道

给 DSH 插件用的本机接口：插件连上后，会话里的 /dsh 命令才会转给它。
