随包只有 node.exe、npm 和 dsh 本体；依赖在第一次启动时从 npm 源下载安装（约 835MB，1–2 分钟）。安装过程关闭了第三方安装脚本（--ignore-scripts），并按 package-lock 校验完整性。

用法：点「安装并启动」，窗口里选工作目录就能开工；窗口关掉只是关界面，dsh 还在跑。模型与凭据在 dsh 自己的设置里填，这里只管启停、不代管钥匙。关掉宿主会一起收掉 dsh 和它的窗口。
